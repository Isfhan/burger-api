# Context Example

Demonstrates all `BurgerContext` properties in action.

## Properties Shown

- `ctx.cookies` — parsed request cookies
- `ctx.headers` — request headers
- `ctx.set` — response mutation (status, headers)
- `ctx.config` — route config from `config.ts`
- `ctx.json()` — body parsing
- `ctx.method`, `ctx.url` — request metadata

## Run

```bash
bun run src/index.ts
```
