# Basic Example (JavaScript)

Minimal BurgerAPI app with a single JavaScript route. Demonstrates the
`--lang js` conventions: `.js` route files with JSDoc types, `jsconfig.json`
with `checkJs: true`, and no TypeScript.

## Run

```bash
bun link burger-api
bun run src/index.js
```

## Test

```bash
bun test api.test.ts
```
